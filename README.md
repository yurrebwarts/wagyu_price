# Git Lesson

## リモートレポジトリとローカルリポジトリとはなんでしょうか？
・リモートリポジトリ
ネット上に配置して複数人で共有するためのリポジトリ。

・ローカルリポジトリ
開発者一人ひとりが使用するために自分のPC上に配置するためのリポジトリ。

## プッシュとマージの違いはなんでしょうか？
・プッシュ
ローカルの内容をリモートにアップ

・マージ
別のブランチの作業内容(変更履歴)をブランチに取り込むこと

## コミットとプッシュの違い
・コミット
　変更履歴を残すこと

・プッシュ
　Gitに保存した履歴をGitHubへ送る

## コミットのメッセージはどのように書いてあげるのが適切でしょうか？
その履歴がどんな編集を行なったのかを示す


## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
・ローカルでマージ
　自分のPC上でマージして、その結果をGitHubへPushする方法。

・プルリクエスト
　変更内容をマージをしてくださいという依頼を行うこと


## コンフリクトを起こしてしまった場合、どう対処すべきですか？
　1.先にマージされた変更内容を取り込む
  2.後にマージしようとしている変更内容を取り込む
  3.どちらの変更内容も取り込む
